## 2026-01-15: Order ID display improvements

### Completed
- PRD item: "Each order added should show the header with a short syntax like git commits..."

### Key decisions
- Order ID structure: requestor_address (42 chars) + unique_suffix (8+ chars)
- Short ID display: first 8 chars of suffix (like git's 7-char hash)
- Auto-fetch API on add: gets created_at_iso and request_status
- Auto-opens view panel after adding order
- Minimized hex repetition: shows suffix only, not full requestor address prefix

### Changes
- web/src/App.svelte:
  - Added `createdAt` and `status` fields to TrackedRequest interface
  - Added helper functions: getOrderSuffix(), getShortOrderId(), formatOrderTime()
  - Updated addTrackedRequest() to async, auto-fetch API, auto-open view panel
  - New UI layout: short ID badge + status tag on first line, ISO timestamp on second
  - Added CSS for .short-order-id, .order-status, .order-time, .request-header-line
  - Removed unused CSS selectors

### Notes
- If API call fails, gracefully falls back to showing suffix without metadata
- Status displayed with same color coding as detail panel

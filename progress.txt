## 2026-01-15: Improved request details view in Requestor Tracker

- Total cycles displayed with M/B suffix using formatCycles()

- Added lock_price to display when available
- Updated MarketRequest type with new API fields (timestamps, cycles, lock_price)

Files changed:
- web/src/lib/types.ts - extended MarketRequest interface
- web/src/App.svelte - new formatters, redesigned detail view, copy button per order
